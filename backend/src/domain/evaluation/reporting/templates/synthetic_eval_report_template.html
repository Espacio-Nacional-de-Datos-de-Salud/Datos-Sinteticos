Insights clave

Fidelidad -

Esta seccion evalua si el dataset sintetico reproduce las distribuciones, estadisticas y relaciones entre variables del dataset real. Valores altos indican mayor fidelidad.

Correlations

Estructura de correlaciones del dato real (gris) y sintetico (verde), y la diferencia absoluta (rojo). Cuanto mas se parezcan real y sintetico, mejor se conservan las relaciones entre variables.

Univariate distributions

Para cada columna se compara la distribucion real (gris) con la sintetica (verde). El area sombreada marca la diferencia entre ambas.

Bivariate distributions

Distribucion conjunta de pares de columnas: original (gris) frente a sintetico (verde). Se muestran los pares peor reproducidos.

Accuracy

Accuracy por columna (1-TVD): univariante, y media de las accuracies bivariantes y trivariantes en las que participa cada columna. La matriz muestra 1-TVD univariante en la diagonal y bivariante en el resto.

Privacidad -

Esta seccion evalua el riesgo de que los datos sinteticos revelen informacion de registros reales o permitan re-identificacion. Valores altos indican menor riesgo.

La penalizacion de privacidad se calcula a partir de los subsets donde el k-anonymity sintetico empeora respecto al real. Penalizaciones altas indican mas combinaciones potencialmente identificables.

Utilidad -

Esta seccion muestra pruebas de utilidad orientadas al uso del dataset sintetico. No participa en el score global. Actualmente incluye utilidad predictiva mediante modelos entrenados con datos reales y sinteticos; en futuras versiones tambien incluira baterias de metricas estadisticas definidas por el usuario.

Pruebas de utilidad estadística

Estas pruebas comparan indicadores definidos por el usuario entre el dataset real y el sintético. El score se calcula a partir del error relativo ponderado por la importancia de cada prueba. Esta sección es informativa y no modifica el score global.

Interpretacion TSTR: GT es rendimiento entrenando y evaluando con datos reales. SYN_ID entrena con sinteticos y evalua en test in-distribution. SYN_OOD entrena con sinteticos y evalua en escenario out-of-distribution. Cuanto mas cercanos a GT esten SYN_ID y SYN_OOD, mayor utilidad predictiva. Esta informacion es diagnostica y no modifica el score global.
