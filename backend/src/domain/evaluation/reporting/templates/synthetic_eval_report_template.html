Cómo leer este reporte

Este informe ayuda a decidir si el dataset sintético es adecuado para su uso. El Balance Fidelidad/Privacidad resume los dos ejes principales; la utilidad se muestra como dimensión complementaria para valorar si el dato sintético sirve para el caso de uso previsto.

Fidelidad ¿El sintético reproduce correctamente las propiedades estadísticas del real?
Privacidad ¿Existe riesgo de re-identificación o de fuga de registros reales?
Utilidad ¿Los datos sintéticos siguen siendo útiles para entrenar modelos predictivos o reproducir indicadores estadísticos?
Ver guía detallada de interpretación, contenido y limitaciones

Este reporte no certifica automáticamente que un dataset sintético sea apto para cualquier uso. Sirve para comparar evidencia de fidelidad, privacidad y utilidad, y para decidir si el resultado encaja con el caso de uso, el nivel de riesgo aceptable y las reglas de gobierno del dato.

1. Revisa primero el balance principal

  • Fidelidad resume si el sintético conserva distribuciones, relaciones y estadísticos del real.
  • Privacidad resume señales de cercanía excesiva a registros reales, coincidencias o posible re-identificación.
  • El Balance Fidelidad/Privacidad ayuda a ver si el resultado mantiene un equilibrio razonable entre parecido estadístico y protección.

2. Usa la utilidad como validación del caso de uso

  • La utilidad predictiva compara modelos entrenados con datos reales frente a modelos entrenados con sintéticos.
  • La utilidad estadística compara indicadores definidos por el usuario, como proporciones, medias, conteos o tasas.
  • La utilidad es complementaria: no participa en el Balance Fidelidad/Privacidad, pero puede ser decisiva para aprobar o descartar el dataset.

3. Interpreta las métricas con contexto

  • Algunas métricas se muestran transformadas para que valores más altos indiquen mejor resultado; el tooltip explica la transformación cuando aplica.
  • Una puntuación agregada alta puede ocultar problemas en variables concretas, subgrupos o combinaciones de variables.
  • Si una métrica está desactivada o no tiene valor válido, el reporte puede ocultarla para no ocupar espacio ni inducir a error.
Consideraciones: valida siempre las variables críticas del caso de uso, revisa las tablas detalladas y contrasta los resultados con conocimiento experto. Un buen resultado en fidelidad no implica ausencia total de riesgo, y un buen resultado en privacidad puede venir acompañado de pérdida de utilidad.

Utilidad predictiva

Evalúa si los datos sintéticos sirven para entrenar modelos predictivos. Compara modelos entrenados con datos reales frente a modelos entrenados con datos sintéticos. Esta dimensión es informativa y no participa en el Balance Fidelidad/Privacidad.

Score ponderado de utilidad predictiva

Resume el rendimiento relativo de los modelos entrenados con datos sintéticos frente a la referencia real.

Real / GT es la referencia con datos reales. Sintético ID evalúa en distribución y Sintético OOD evalúa fuera de distribución.
