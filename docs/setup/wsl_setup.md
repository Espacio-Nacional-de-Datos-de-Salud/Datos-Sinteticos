# Quick WSL Setup

If you are on Windows, we recommend running this project from **WSL** instead of PowerShell to get a Linux-like environment and avoid shell/path inconsistencies.

## Install WSL and Ubuntu

Open **PowerShell as Administrator**.

Run:

```powershell
wsl --install -d Ubuntu
```

Then restart your machine if prompted, open Ubuntu, and finish the initial Linux user setup.

If you can't find it, you should find Ubuntu by opening a Terminal, and clicking to downwards arrow next to the `+` sign used to create a new terminal in a side tab. There you should find different types of terminals you can open including Powershell, CMD or Ubuntu.

## Linux User
For the Linux user setup I recommend using your linux username for simplicity, if not remember your password you will need to run the Ubuntu terminal as admin for `sudo` commands.
